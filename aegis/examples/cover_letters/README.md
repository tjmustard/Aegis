# Cover Letter Examples

This folder holds example generated cover letters (PDFs) used as visual references when designing or adjusting the `coverletter2.typ` template.

## What belongs here

- `<Company> - <Role>.pdf` — A rendered cover letter PDF produced by the Aegis pipeline

These files are gitignored (personal data). To use the system, run the `/aegis-generate` command against an application folder; the output PDF will appear in that application's folder under `Applications/`.

## Purpose

The Aegis skills (`/cover-letter`, `/aegis-tailor`, `/aegis-generate`) use files in this folder as visual layout references when adjusting typography, spacing, or page length. One or two representative PDFs here are sufficient.
